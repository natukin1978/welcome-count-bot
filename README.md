# WelcomeカウントBOT

<img src="./images/main.png" width="25%">

筋トレ配信者の、筋トレ配信者による、筋トレ配信者のための、BOTです。

来訪者（初見さん・常連さん）のチャットを検知して筋トレの「未消化数」を自動的に加算し、音声認識によるカウントダウンと連動して消化・集計を行う、ライブ配信支援用バックエンドシステム（WebSocketサーバー）です。

備考: 本システムはフロントエンド表示用の[筋トレオーバーレイ](https://github.com/natukin1978/workout-overlay)とWebSocketを介してシームレスに連携し、リアルタイムに画面へ数値を同期・反映する設計になっています。

## 主な機能

- 自動未消化加算（ウェルカムカウント）

来訪者の初コメントをトリガーに、設定に応じた回数（初見/通常）を「未消化数（undone）」に自動プールします。

※ 要 [電脳娘フユカ (AIモデレーター Fuyuka API)](https://github.com/natukin1978/ai-moderator-fuyuka)

- 音声認識連動型カウントダウン音声認識

テキストを解析し、自動で筋トレモードの切り替えや回数の消化を行います。

※ 要 [ゆかコネNEO](https://nmori.github.io/yncneo-Docs/)

## 音声コマンド一覧

音声入力（プレーンテキスト）として受け取った文字列を解析し、以下の挙動を行います。

| コマンド例                      | 挙動                                                                                                                                                | 実行条件                               |
|---------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------|
| 「筋トレ 十回 追加で」          | 未消化数（undone）に指定された数を純粋に加算します。                                                                                                | いつでも有効                           |
| 「今から筋トレ 十回 やります」  | 音声モードへ移行し、次の減算比較用の基準値を 10 に固定します。（この時点では未消化数は減りません）                                                  | 現在の undone が 10以上 の場合のみ有効 |
| 「筋トレ開始します」            | 指定回数なしで音声モード（カウント待ち状態）へ移行します。                                                                                          | いつでも有効                           |
| 「9」「8」...（カウントダウン） | 基準値からの減少分を検知し、total を加算、undone を減算します。（※1度に最大3カウントまでの誤差・飛びを許容） 0 になると自動で通常モードに戻ります。 | 音声モード中のみ有効                   |

## セットアップと起動方法

`ConfigApp.exe`を実行して入力を進める事で設定する事ができます。(最後に「保存」をお忘れなく)

`WelcomeCountBot.exe`を実行して本体を起動します。

### OBS Studio に配置する場合

1. OBSの「ソース」パネルにある `+` ボタンをクリックし、「ブラウザ」を選択します。
2. URLの欄に以下のURLを入力します。

```
https://natukin1978.github.io/workout-overlay/?vol=33
```

vol=33 の部分は効果音の音量（ボリューム）です。0（消音）から 100（最大）までお好みに合わせて調整してください。

サイズ（幅・高さ）を配信画面のレイアウトに合わせて調整し、「OK」をクリックします。

### 外部から操作する場合

Webブラウザから以下にアクセスします。
```
https://natukin1978.github.io/workout-overlay/
```

💡ヒント💡

OBSの`ドック`にある`カスタムブラウザドック`という機能を使って、
OBSのドックとして扱うのもオススメです。

## 開発者向け情報（API / WebSocket）

本ボットは以下のエンドポイントを提供し、workout-overlay 等のクライアントと双方向通信を行います。

- WebSocket接続先: ws://localhost:[ポート]/workout
- 送信される主なイベント（JSON）:
 - - MODE_CHANGE: 音声モード（voice）と通常モード（normal）の切り替え通知
 - - ADD_UNDONE: 未消化数の加算DIGEST / DIGEST_MULTI: 筋トレの消化（1回、または複数回の一括消化）
 - - SYNC_STATE: 接続確立時の初期状態同期
